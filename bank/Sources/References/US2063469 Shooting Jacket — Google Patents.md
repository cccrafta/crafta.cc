## Summary
Patent for a padded shooting jacket whose main novelty is a pad on the upper sleeve where the gun sling grips the arm. It suggests an inverted box pleat back for comfort and freedom, documenting the pleated back as a sport feature in 1936. The page text was OCR-garbled, so quotes are fragments.
## Key Claims
- Inventor Howard O. Smith; filed 29 January 1936, granted 8 December 1936.
- The inventor suggests an inverted box pleat back for more comfort and freedom of movement; the text reads "inverted box pleat back type shown in Fig. 2".
- Main novelty is a pad around the upper sleeve where the gun sling grips the arm; the garment is described as "refined in appearance, durable in use, economical in manufacture".
- Describes such garments as "universally used by sportsmen"; the drawn version suits right-handed shooters, with sling pad and shoulder pad switching sides for left-handed shooters.
- Use with US 2,323,777 (Katz, 1943): a pleated back appears in sport garments (1936) and work garments (1941-43), which shows the same device in both traditions but not which came first.
